# Style references from the owner

What the owner wants the game to look like, as pictures and short clips. Every agent working on
the look reads this file first. Use the references for direction (colour, light, brushwork, the
figure, the level of detail), never to copy one specific game: we make our own worlds.

The repository is public. Keep an image here only if the owner made it or it is free to share;
for anything else, keep only the written note (what to take from it) and ask the owner to
upload it again to the session that needs it.

## How to add one

One line per reference, newest last:

`<file or "uploaded in chat, not kept">` | where it is from | what to take from it (colour /
light / brushwork / sky / water / the figure / detail) | what NOT to take
